# Encounter XP budgets

The Campaign workspace shows a small calculator only when its pinned Ruleset Version is SRD 5.2.1. It uses the **XP Budget per Character** table in [Combat Encounters, printed page 202](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf#page=202). The table provides low, moderate, and high budgets for levels 1–20. The calculator multiplies the selected level's three values by the number of characters, then sums the XP values entered for individual creatures. It compares that sum with each budget without treating the result as a guarantee of encounter difficulty.

This first calculation assumes all characters have the same level. Creature XP comes from the GM's entries; it does not infer XP from CR or store an Encounter. Party composition, character levels, and creature selections are not yet persisted as mechanical data. The later Encounter Builder can add those inputs and reusable definitions through the Ruleset boundary.

The rules reference index is version-scoped and links to the official SRD PDF. Source, license, and attribution remain visible in the Campaign workspace. The repository stores only the small reference index and the numeric budget table, not a copy of the full SRD.
