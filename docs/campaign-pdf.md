# Campaign PDF module

The Campaign workspace offers a private PDF download at `export/pdf`. It uses the same owner-authorized, repeatable-read snapshot and chapter model as the [Markdown module](campaign-module.md). Snapshot collection finishes before rendering begins. The export performs no writes and adds no persistence or dependencies to Campaign Core.

The A4 document contains the compass, an index with page links, chapter bookmarks, page numbers, and the detailed available reference. Preparation and outcomes keep separate labels. Archived and trashed entities are omitted; recorded Encounter Runs and Reward Grants retain their historical snapshots. This is a GM document containing Secrets and outcomes, with a warning on the first page and a GM-only footer on every page. Authentication and missing/foreign Campaign responses match the other downloads. Responses are attachments with `private, no-store` and `nosniff` headers.

The renderer uses server-side pdfmake with its packaged Roboto fonts. Next.js keeps this package external so its font paths also work in production. Fonts are embedded and cover Latin accents, Greek, and Cyrillic; this first layout does not promise CJK or emoji coverage. The renderer styles the reference's headings and labels, preserves GM-authored text as text, and never loads user-supplied HTML, images, files, or URLs. Markdown links inside GM notes remain literal text. There is no browser renderer or external asset request. JSON remains the complete portability format, including recoverable material; PDF is a reading/printing format.

Validation covers the shared filtering and chapter model, separate preparation and outcomes, literal resource-looking text, empty Campaigns, embedded fonts, real multipage generation, private response headers, and authentication/owner isolation. Local visual review includes accented names, Greek and Cyrillic, the index, long records, continuation pages, and final chapters. The shared PostgreSQL export integration tests cover authorized, consistent snapshot collection.

This first PDF layout is the full campaign module. Focused Session/quick-reference PDF layouts, custom typography, player-safe publishing, and import are later work.
