# Superpowers skill selection

The Superpowers skills in this directory are available individually. Select the narrow process skill that fits the current user request. The repository's AGENTS.md, user instructions, and Codex tool rules take priority. Do not require a skill for every conversation or trigger delegation without a user request. Read [upstream instructions](UPSTREAM-SKILL.md) when the user explicitly requests the upstream bootstrap behavior.
